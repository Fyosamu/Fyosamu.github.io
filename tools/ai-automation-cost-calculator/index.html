Questions people actually ask

Why does the same automation cost $900 or $3,000?

Number of systems it touches and whether a human has to approve anything. Two tools talking is fast. Five tools, with money moving and a person signing off, is a different build.

What about the monthly cost of the AI itself?

API models usually run $10 – $80 a month at small volumes, and the dashboard we ship shows cost per run so it never surprises you. The self-hosted option removes that bill entirely.

Is my data used for training?

No. We wire the build to a zero-retention API mode, or to a self-hosted model if the data cannot leave your servers at all.

Can I start with one workflow and add more later?

That is how most projects start. The first build sets the patterns and the tests, so the second one is noticeably cheaper.

Do I need a call to see the real number?

No. Send the scope, get the number, decide. If it does not fit, you lost two minutes instead of an afternoon.
