Questions people actually ask

Do you work with Telegram only?

No. Telegram, Discord and WhatsApp — plus anything with a webhook API. Telegram is where we've shipped most, including our own product.

Where does the bot run?

Anywhere Python or Node runs: your VPS, a small cloud box, or a container. We set it up as a 24/7 service with auto-restart and tell you exactly how it's wired.

Do I need to know how to code?

No. Everything you'd want to change — texts, schedules, thresholds, admin lists — lives in a config file, and we document it.

Often, yes. Send the code or the symptoms. If it's a rewrite rather than a repair, we'll say so and quote it as one.
